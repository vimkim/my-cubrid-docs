8장 — dirty 추적, WAL 결합 flush, 데몬, checkpoint

이 장의 범위 페이지가 더러워지는 순간부터 디스크에 안착하는 순간까지의 전 구간을 규정한다: dirty 비트와 oldest_unflush_lsa의 회계 규칙, 모든 데이터 페이지 쓰기가 통과하는 단일 깔때기 pgbuf_bcb_flush_with_wal, 그 위에 얹힌 안전 래퍼, 백그라운드 데몬 4종, flush 속도를 제어하는 토큰 버킷, victim 후보 flush, checkpoint 순차 flusher, 그리고 pgbuf_flush_all 계열.

DWB(Double Write Buffer) 내부는 이 장의 범위가 아니다 — 여기서는 pgbuf가 호출하는 dwb_is_created() / dwb_set_data_on_next_slot() / dwb_add_page() 세 진입점의 관측 가능한 계약만 쓴다. 실제 계약 표는 9장에 있다.

8.1 dirty 규약

8.1.1 dirty 비트는 BCB flags의 한 비트다

dirty는 별도 필드가 아니라 원자적으로 갱신되는 PGBUF_BCB::flags(int) 안의 한 비트다 page_buffer.c:222-241. 이 장에서 쓰이는 세 비트:

비트값의미
PGBUF_BCB_DIRTY_FLAG0x80000000페이지가 수정됨. 디스크에 쓰이면 해제
PGBUF_BCB_FLUSHING_TO_DISK_FLAG0x40000000누군가 이 BCB를 디스크에 쓰는 중. DIRTY는 보통 꺼져 있지만 flush가 성공하기 전까지 victim이 될 수 없다
PGBUF_BCB_ASYNC_FLUSH_REQ0x02000000비동기 flush 요청 — latch 보유자가 unfix 때 대신 flush해 달라는 부탁

DIRTY와 FLUSHING_TO_DISK는 둘 다 PGBUF_BCB_INVALID_VICTIM_CANDIDATE_MASK page_buffer.c:258-262의 구성원이다 — 즉 dirty해지는 것도, flush 중인 것도 victim 후보 자격을 박탈한다. 나머지 둘은 VICTIM_DIRECT와 INVALIDATE_DIRECT_VICTIM이며 7장 소관이다.

8.1.2 pgbuf_bcb_set_dirty — 손으로 쓴 CAS 핫패스

dirty 설정만은 일반 경로인 pgbuf_bcb_update_flags를 일부러 우회한다. 소스 주석이 이유를 직접 말한다: "가장 많이 쓰이는 경우이므로 코드가 최대한 최적이어야 한다" page_buffer.c:15971-15972.

/* 사전조건: 호출자는 이 BCB의 페이지를 WRITE latch로 고정하고 있어야 한다.
 *           BCB mutex는 필요 없다 — flags CAS만으로 충분하다. */
void pgbuf_bcb_set_dirty (THREAD_ENTRY *thread_p, PGBUF_BCB *bcb)      /* :15967-15995 */
{
  int old_flags;
  do
    {
      old_flags = bcb->flags;
      if (old_flags & PGBUF_BCB_DIRTY_FLAG)
        {
          return;                    /* 이미 dirty — 카운터도 건드리지 않고 즉시 반환 (:15978-15982) */
        }
    }
  while (!ATOMIC_CAS_32 (&bcb->flags, old_flags, old_flags | PGBUF_BCB_DIRTY_FLAG));
  /* clean → dirty 전이가 이 스레드에서 성사됐다. 회계는 딱 한 번만 일어난다. */
  ATOMIC_INC_64 (&pgbuf_Pool.monitor.dirties_cnt, 1);                 /* :15987 */
  assert (0 <= pgbuf_Pool.monitor.dirties_cnt
          && pgbuf_Pool.monitor.dirties_cnt <= pgbuf_Pool.num_buffers);
  /* zone3에 있었고 다른 무효화 플래그가 하나도 없었다면, 이제 막 victim 후보에서 이탈한 것이다.
   * old_flags 기준으로 판단한다 — 새 flags에는 방금 우리가 켠 DIRTY가 들어 있으므로. */
  if (PGBUF_GET_ZONE (old_flags) == PGBUF_LRU_3_ZONE
      && (old_flags & PGBUF_BCB_INVALID_VICTIM_CANDIDATE_MASK) == 0)
    {
      pgbuf_lru_remove_victim_candidate (thread_p, pgbuf_lru_list_from_bcb (bcb), bcb);   /* :15990-15994 */
    }
}

MUST 재구현은 이 세 가지를 정확히 지켜야 한다: (1) 이미 dirty면 카운터를 올리지 않고 반환, (2) dirties_cnt는 clean→dirty 전이당 정확히 +1, (3) victim-candidate 이탈 판정은 CAS 이전의 flags로 한다.

8.1.3 해제 경로는 일반 경로를 탄다

pgbuf_bcb_clear_dirty page_buffer.c:16003-16008는 그냥 pgbuf_bcb_update_flags (thread_p, bcb, /*set*/ 0, /*clear*/ DIRTY)다. 일반 경로는 CAS 성공 후 두 종류의 회계를 한다 — zone3 BCB의 victim-candidate 카운터 증감 page_buffer.c:15755-15777과, old/new flags의 dirty 비트를 diff한 dirties_cnt ±1 page_buffer.c:15779-15793.

8.1.5 dirties_cnt의 위치와 회계 규칙

INT64 dirties_cnt는 PGBUF_PAGE_MONITOR의 첫 번째 필드다 page_buffer.c:693-695 — pgbuf_Pool.monitor.dirties_cnt page_buffer.c:779로 접근한다. 초기화 시 0 page_buffer.c:1628, 1773, 13999.

회계 규칙
  • 이것이 유일한 전역 dirty 카운터다. SHOW PAGE BUFFER STATUS와 pgbuf_peek_stats는 이 값을 쓰지 않고 BCB 테이블을 각자 스캔해 따로 센다(8.11).
  • 증감 지점은 정확히 두 곳: pgbuf_bcb_set_dirty(+1)와 pgbuf_bcb_update_flags의 diff(±1). MUST 다른 어떤 경로도 이 값을 만지지 않는다.
  • 소비자는 단 하나 — pgbuf_flush_control_from_dirty_ratio()(8.8). 즉 이 카운터의 정확도가 적응형 flush 속도 제어의 입력 정확도다.

풀 밖으로 나가는 모든 데이터 페이지 쓰기는 예외 없이 이 함수를 통과한다. page_buffer.c:10670-10898

STATIC_INLINE int

8.3.1 진입 계약

사전조건 (MUST)
  1. 호출자가 BCB mutex를 보유한 채 진입한다 — PGBUF_BCB_CHECK_OWN (bufptr) :10691. 함수는 즉시 *is_bcb_locked = true로 시작한다 :10694.
  2. latch 상태는 PGBUF_NO_LATCH, PGBUF_LATCH_READ, PGBUF_LATCH_WRITE 셋 중 하나여야 한다 :10696-10697.
  3. WRITE latch 상태에서의 flush는 허용된다 — 단 그 latch 보유자가 나 자신일 때만. 디버그+SERVER_MODE 빌드에서 thrd_hold_list를 걸어 내려가며 holder != NULL을 assert해 확인한다 :10698-10717. 이 허용 규칙이 있어서 pgbuf_flush_with_wal을 수정 도중에도 부를 수 있다.
  4. 기회/타당성 판단은 호출자 책임이다. 이 함수는 "지금 flush해도 되는가"를 묻지 않는다 :10719-10731.
사후조건. *is_bcb_locked로 BCB mutex 보유 여부를 반드시 출력한다. 성공 경로에서도 잠긴 채 나가는 경우와 풀린 채 나가는 경우가 모두 존재하므로(8.3.5), 호출자는 이 out 파라미터만 보고 unlock 여부를 결정해야 한다.

  /* ─ 표시 ─ FLUSHING_TO_DISK를 세우고 DIRTY·ASYNC_FLUSH_REQ를 끈다.     (:10739) */
  was_dirty = pgbuf_bcb_mark_is_flushing (thread_p, bufptr);
  uses_dwb = dwb_is_created () && !is_temp;                  /* temp 볼륨은 DWB 미경유 (:10741) */
start_copy_page:
  iopage = (FILEIO_PAGE *) PTR_ALIGN (page_buf, MAX_ALIGNMENT);          /* (:10744) */
  tde_algo = pgbuf_get_tde_algorithm (pgptr);
  if (tde_algo != TDE_ALGORITHM_NONE)
    {
      /* TDE: 암호문을 스택 버퍼로 직접 생성                              (:10747-10755) */
      error = tde_encrypt_data_page (&bufptr->iopage_buffer->iopage, tde_algo, is_temp, iopage);
      if (error != NO_ERROR)
        {
          ASSERT_ERROR ();
          return error;          /* ← D1: FLUSHING 플래그를 원복하지 않고 나간다 (8.3.6) */
        }
    }
  else
    {
      memcpy (iopage, &bufptr->iopage_buffer->iopage, IO_PAGESIZE);     /* (:10758) */
    }
  if (uses_dwb)
    {
      /* DWB 슬롯으로 즉시 재복사. can_wait = false — 여기서 막히면 안 된다.
       * BCB mutex를 쥔 채로 블록되는 것을 피하기 위한 설계다.             (:10760-10772) */
      error = dwb_set_data_on_next_slot (thread_p, iopage, false /*can_wait*/, false, &dwb_slot);
      if (error != NO_ERROR)
        {
          return error;          /* ← D1: 두 번째 누수 지점 (8.3.6) */
        }
      if (dwb_slot != NULL)
        {
          iopage = NULL;         /* 데이터는 이미 슬롯 안에 있다 */
          goto copy_unflushed_lsa;      /* ← dead goto: 라벨이 바로 다음 줄이다 */
        }
      /* dwb_slot == NULL이면 슬롯을 못 얻은 것 — iopage를 그대로 들고 아래로 간다.
       * 실제 슬롯 확보는 dwb_add_page가 can_wait = true로 재시도한다. */
    }
copy_unflushed_lsa:
  LSA_COPY (&lsa, &bufptr->iopage_buffer->iopage.prv.lsa);    /* 현재 LSA 캡처   (:10775) */
  LSA_COPY (&oldest_unflush_lsa, &bufptr->oldest_unflush_lsa);  /* 저장           (:10776) */
  LSA_SET_NULL (&bufptr->oldest_unflush_lsa);                 /* 그리고 지운다   (:10777) */
  PGBUF_BCB_UNLOCK (bufptr);   *is_bcb_locked = false;        /* [BCB mutex 해제] (:10779-10780)
                                                               * ★ 디스크 쓰기는 mutex 없이 한다 */
  /* ─ WAL 게이트 ─                                                        (:10782-10795) */
  if (!LSA_ISNULL (&oldest_unflush_lsa))
    {
      logpb_flush_log_for_wal (thread_p, &lsa);   /* 판단은 oldest, 대상은 current! */
    }
  else
    {
      /* 페이지가 수정됐지만 로깅되지 않은 희귀 케이스. 에러가 아니다. */
      if (!pgbuf_is_temporary_volume (bufptr->vpid.volid))
        {
          er_log_debug (ARG_FILE_LINE, "flushing page %d|%d to disk without logging.\n", ...);
        }
    }
  /* ─ 쓰기 ─ */
  if (uses_dwb)
    {
      error = dwb_add_page (thread_p, iopage, &bufptr->vpid, false, &dwb_slot);   /* (:10811) */
      if (error == NO_ERROR && dwb_slot == NULL)
        {
          /* 그 사이 DWB가 파괴됐다. BCB를 다시 잠그고 처음부터 — DWB 없이.  (:10814-10821) */
          uses_dwb = false;
          PGBUF_BCB_LOCK (bufptr);   *is_bcb_locked = true;
          goto start_copy_page;
        }
    }
  else
    {
      show_status->num_pages_written++;                       /* SHOW용 per-thread 카운터 */
      /* DWB가 살아 있는데 여기 왔다면(temp 볼륨) 토큰/fsync 보상을 건너뛴다 */
      write_mode = dwb_is_created () ? FILEIO_WRITE_NO_COMPENSATE_WRITE : FILEIO_WRITE_DEFAULT_WRITE;
      perfmon_inc_stat (thread_p, PSTAT_PB_NUM_IOWRITES);     /* ← 여기서만 오른다 (:10831) */
      if (fileio_write (thread_p, fileio_get_volume_descriptor (bufptr->vpid.volid),
                        iopage, bufptr->vpid.pageid, IO_PAGESIZE, write_mode) == NULL)
        {
          error = ER_FAILED;
        }
    }
  /* ─ 실패 경로 ─                                                         (:10846-10861) */
  if (error != NO_ERROR)
    {
      PGBUF_BCB_LOCK (bufptr);   *is_bcb_locked = true;
      pgbuf_bcb_mark_was_not_flushed (thread_p, bufptr, was_dirty);   /* FLUSHING 해제, 원래 dirty였으면 DIRTY 복원 */
      LSA_COPY (&bufptr->oldest_unflush_lsa, &oldest_unflush_lsa);   /* 무조건 덮어쓴다 */
      if (bufptr->next_wait_thrd != NULL)
        {
          pgbuf_wake_flush_waiters (thread_p, bufptr);
        }
      return ER_FAILED;         /* 잠긴 채 반환 */
    }
  assert (get_latch (&bufptr->atomic_latch) != PGBUF_LATCH_FLUSH);
  /* ─ 성공 경로 (2분기) ─ */
  if (is_page_flush_thread && pgbuf_Page_post_flush_daemon != NULL
      && pgbuf_is_any_thread_waiting_for_direct_victim ()
      && pgbuf_Pool.flushed_bcbs->produce (bufptr))                     /* (:10865-10876) */
    {
      /* 후속 처리를 post-flush 데몬에 위임한다.
       * ★ BCB는 잠기지 않은 채, FLUSHING_TO_DISK가 여전히 켜진 채로 남는다.
       *   플래그 해제와 대기자 기상은 pgbuf_assign_flushed_pages가 대신 한다. */
      pgbuf_Page_post_flush_daemon->wakeup ();
      if (perfmon_is_perf_tracking_and_active (PERFMON_ACTIVATION_FLAG_PB_VICTIMIZATION))
        {
          perfmon_inc_stat (thread_p, PSTAT_PB_FLUSH_SEND_DIRTY_TO_POST_FLUSH);
        }
    }
  else
    {
      PGBUF_BCB_LOCK (bufptr);   *is_bcb_locked = true;                /* (:10880-10889) */
      pgbuf_bcb_mark_was_flushed (thread_p, bufptr);                   /* FLUSHING 해제 */
      if (bufptr->next_wait_thrd != NULL)
        {
          pgbuf_wake_flush_waiters (thread_p, bufptr);
        }
    }
  if (perfmon_is_perf_tracking_and_active (PERFMON_ACTIVATION_FLAG_PB_VICTIMIZATION))
    {
      perfmon_inc_stat (thread_p, PSTAT_PB_FLUSH_PAGE_FLUSHED);        /* (:10894) */
    }
  return NO_ERROR;
}

8.3.4 WAL 게이트의 비대칭

핵심 규칙 flush 여부의 판단은 oldest_unflush_lsa로 하고, 로그 관리자에 넘기는 대상은 페이지의 현재 LSA다. page_buffer.c:10782-10795

  • 판단: oldest_unflush_lsa가 NULL이 아니다 = "이 페이지에 대해 로깅된 것이 하나라도 있다". NULL이면 로그 flush를 아예 부르지 않는다.
  • 대상: logpb_flush_log_for_wal (thread_p, &lsa)의 lsa는 BCB에서 방금 캡처한 페이지 헤더의 현재 LSA — 이 페이지를 건드린 가장 최신 로그 레코드. WAL이 실제로 요구하는 것이 바로 이것이다.
가장 오래된 것으로 판단하고 가장 새것까지 밀어 넣는 이 비대칭을 MUST 그대로 재현해야 한다. 둘 다 oldest로 하면 WAL이 깨지고, 둘 다 current로 하면 로깅 없는 dirty 페이지에서 불필요한 로그 flush가 발생한다.

8.3.5 실패 경로와 flush 대기자

실패 경로는 oldest_unflush_lsa를 무조건 저장값으로 덮어쓴다. mutex가 풀린 구간에서 동시 pgbuf_set_lsa가 더 새 값을 채웠다면 그 값이 지워진다. 저장된(더 오래된) 값이 항상 새 값 이하인지는 미검증이다 — 만약 그렇다면 효과는 보수적(더 이른 시점에 다시 flush)이지 안전하지 않은 쪽은 아니다.

flush 완료를 기다리는 것은 PGBUF_LATCH_FLUSH라는 의사 latch 모드로 bcb->next_wait_thrd에 큐잉하는 형태다.

static void pgbuf_wake_flush_waiters (THREAD_ENTRY *thread_p, PGBUF_BCB *bcb)   /* :10907-10957 */
{
  PERF_UTIME_TRACKER_START (thread_p, &timetr);
  PGBUF_BCB_CHECK_OWN (bcb);                 /* [BCB mutex 보유 필수] */
  /* 대기 리스트를 훑어 PGBUF_LATCH_FLUSH 대기자만 골라 dequeue + 기상.
   * reader/writer 대기자는 큐에 그대로 남긴다.                          (:10920-10943) */
  for (crt = bcb->next_wait_thrd; crt != NULL; crt = save_next)
    {
      save_next = crt->next_wait_thrd;
      if (crt->request_latch_mode == PGBUF_LATCH_FLUSH)
        {  unlink (crt);  pgbuf_wakeup_uncond (crt);  }
      else
        {  prev = crt;  }
    }
  /* ★ atomic latch의 waiter_exists 비트 정리. 이것이 없으면 CREATE INDEX 라이브락이 난다.
   *   (:10944-10953 주석) 비트가 남아 있으면 pgbuf_latch_bcb_upon_fix의 idle-grant CAS가
   *   waiter_exists == false를 강제 기대하는데 latch_mode == PGBUF_NO_LATCH에서 enqueue도
   *   하지 않아, 다음 fix가 BCB mutex를 쥔 채 영원히 스핀한다. */
  if (!pgbuf_is_exist_blocked_reader_writer (bcb))
    {
      set_waiter_exists (&bcb->atomic_latch, false);
    }
  PERF_UTIME_TRACKER_TIME (thread_p, &timetr, PSTAT_PB_WAKE_FLUSH_WAITER);    /* (:10955) */
}

8.4 안전 래퍼 — 즉시 flush가 불가능할 때

pgbuf_bcb_flush_with_wal은 아무 검사도 하지 않는다. 일반 호출자가 쓰는 것은 그 위의 pgbuf_bcb_safe_flush_internal page_buffer.c:8764-8846이다. 주석이 즉시 flush가 불가능한 두 경우를 명시한다 :8783-8791:

  1. 다른 스레드가 WRITE latch를 쥐고 있다. "latch 보유자가 언제 수정을 하는지 알 수 없다." → ASYNC_FLUSH_REQ를 세워 보유자가 unfix 때 대신 flush하게 한다.
  2. 다른 스레드가 이미 flush 중이다. "동시 flush 다중 허용은 안전하지 않다 — 디스크 쓰기 순서를 보장할 수 없으므로 이론적으로 새 버전 위에 옛 버전을 덮어쓸 수 있다." → BCB 대기 리스트에 큐잉한다.
static int
pgbuf_bcb_safe_flush_internal (THREAD_ENTRY *thread_p, PGBUF_BCB *bufptr, bool synchronous, bool *locked)
{
  assert (get_latch (&bufptr->atomic_latch) != PGBUF_LATCH_FLUSH);
  PGBUF_BCB_CHECK_OWN (bufptr);   *locked = true;             /* [BCB mutex 보유로 진입] */
  if (!pgbuf_bcb_is_dirty (bufptr))
    {
      return NO_ERROR;              /* dirty가 아니면 할 일 없음 — 잠긴 채 반환 (:8777-8781) */
    }
  /* atomic latch에 대한 CAS 루프. 즉시 flush 가능 여부를 판정하고,
   * 동기 대기가 필요하면 같은 CAS로 waiter_exists를 켠다.               (:8793-8818) */
  do
    {
      immediate_flush = block = false;
      impl = get_impl (&bufptr->atomic_latch);   impl_new = impl;
      is_flushing = pgbuf_bcb_is_flushing (bufptr);
      if (!is_flushing
          && (impl.impl.latch_mode == PGBUF_NO_LATCH
              || impl.impl.latch_mode == PGBUF_LATCH_READ
              || (impl.impl.latch_mode == PGBUF_LATCH_WRITE
                  && pgbuf_find_thrd_holder (thread_p, bufptr) != NULL)))    /* WRITE는 나여야 한다 */
        {
          immediate_flush = true;
        }
      else
        {
          assert (is_flushing || impl.impl.latch_mode == PGBUF_LATCH_WRITE);
          if (synchronous)
            {
              block = true;
              impl_new.impl.waiter_exists = true;
            }
        }
    }
  while (!CAS (bufptr->atomic_latch, impl, impl_new));
  if (immediate_flush)
    {
      return pgbuf_bcb_flush_with_wal (thread_p, bufptr, false /*is_page_flush_thread*/, locked);   /* (:8823) */
    }
  /* 남의 WRITE latch 아래다 — 보유자에게 unfix 때 flush해 달라고 요청.
   * 이미 flush 중이라면 요청할 필요가 없다(그 flush가 처리할 것이다).   (:8829) */
  if (!is_flushing)
    {
      pgbuf_bcb_update_flags (thread_p, bufptr, PGBUF_BCB_ASYNC_FLUSH_REQ, 0);
    }
  if (block)
    {
      *locked = false;                                        /* [mutex는 block 함수가 놓는다] */
      return pgbuf_block_bcb (thread_p, bufptr, PGBUF_LATCH_FLUSH, 0, false);    /* (:8836) */
    }
  return NO_ERROR;                  /* 비동기 요청만 남기고 잠긴 채 반환 */
}

8.4.2 ASYNC_FLUSH_REQ의 소비 지점

unfix 말미. pgbuf_unlatch_bcb_upon_unfix는 fix count가 0이 된 뒤 LRU 부기를 마치고, 플래그가 서 있으면 pgbuf_bcb_safe_flush_force_unlock (..., synchronous = false)를 호출한다 page_buffer.c:6809-6825. 여기서 발생한 에러는 er_clear()로 삼킨다 — unfix는 실패할 수 없는 연산이기 때문이다. 어느 경로든 mutex는 정확히 한 번 해제된다.

장기 latch 보유자의 폴링. "영구히 latch된 페이지"를 들고 있는 스레드는 주기적으로 pgbuf_flush_if_requested page_buffer.c:3577-3609를 불러야 한다. 헤더 주석은 요청자가 "보통 checkpoint 스레드"라고 적고 있다.

void pgbuf_flush_if_requested (THREAD_ENTRY *thread_p, PAGE_PTR page)      /* :3577-3609 */
{
  /* 검증 레벨 ALL이면 pgbuf_is_valid_page_ptr (실패 시 assert(false) 후 return) */
  CAST_PGPTR_TO_BFPTR (bcb, page);
  assert (!VPID_ISNULL (&bcb->vpid));
  /* 호출자는 WRITE latch 보유자여야 한다 — 아니면 이 함수를 부를 이유가 없다 */

      for (bufptr = list.bottom, i = check_count_this_lru;
           bufptr != NULL && PGBUF_IS_BCB_IN_LRU_VICTIM_ZONE (bufptr) && i > 0;
           bufptr = bufptr->prev_BCB, i--)
        {
          if (pgbuf_bcb_is_dirty (bufptr))
            {
              /* dirty만 후보가 된다. {bufptr, vpid} 쌍을 사전 할당 배열에 적재  (:3774-3780) */
              victim_cand_list[victim_cand_count].bufptr = bufptr;
              victim_cand_list[victim_cand_count].vpid   = bufptr->vpid;
              victim_cand_count++;
            }
          else if (try_direct_assign && pgbuf_is_any_thread_waiting_for_direct_victim ()
                   && pgbuf_is_bcb_victimizable (bufptr, false)
                   && PGBUF_BCB_TRYLOCK (bufptr) == 0)                    /* (:3781-3794) */
            {
              /* clean BCB인데 victim 대기자가 있다 — 즉석에서 직접 배급.
               * "victim이 넉넉한데도 direct victim 대기자가 있는 드문 경우 처리" (:3747-3748) */
              if (pgbuf_is_bcb_victimizable (bufptr, true)
                  && pgbuf_assign_direct_victim (thread_p, bufptr))
                {
                  try_direct_assign = false;    /* 호출당 1회 제한 */
                  *assigned_directly = true;
                  perfmon_inc_stat (thread_p, PSTAT_PB_VICTIM_ASSIGN_DIRECT_SEARCH_FOR_FLUSH);
                }
              PGBUF_BCB_UNLOCK (bufptr);
            }
        }
      pthread_mutex_unlock (&pgbuf_Pool.buf_LRU_list[lru_idx].mutex);
    }
  return victim_cand_count;
}

static int pgbuf_flush_page_and_neighbors_fb (THREAD_ENTRY *thread_p, PGBUF_BCB *bufptr, int *flushed_pages)
{
#define PGBUF_PAGES_COUNT_THRESHOLD 4
  helper->npages = helper->fwd_offset = helper->back_offset = 0;
  /* (1) 중심 등록 후 BCB mutex 해제. 이후 수집은 해시 조회로만 한다 */
  pgbuf_add_bufptr_to_batch (bufptr, 0);
  first_vpid = bufptr->vpid;
  log_newest_oldest_unflush_lsa = bufptr->oldest_unflush_lsa;
  PGBUF_BCB_UNLOCK (bufptr);
  /* (2) 중심에서 forward/backward를 번갈아 확장한다                      (:11799-11909)
   *     forward = pageid+1, +2, … / backward = pageid-1, -2, …
   *     각 후보는 pgbuf_search_hash_chain으로 찾고 BCB mutex를 얻는다. */
  forward = true;  search_nondirty = false;  prev_page_dirty = true;
  for (i = 1; i < PGBUF_NEIGHBOR_PAGES; )
    {
      /* pageid 범위를 넘으면 → 방향 전환, 양방향 다 막히면 중단 (NEIGHBOR_ABORT_RANGE) */
      /* 해시에 없으면(캐시 미보유)   → 방향 전환 또는 중단 */
      /* flush 중이거나 latch > READ  → 방향 전환 또는 중단 */
      if (!pgbuf_bcb_is_dirty (bufptr))
        {
          if (!search_nondirty)
            {
              /* nondirty 모드가 아니면 clean 이웃은 받지 않는다.
               * data_buffer_neighbor_flush_nondirty(기본 false)가 켜져 있으면
               * 방향을 리셋하고 clean도 받는 2차 패스로 전환한다.        (:11819-11829) */
            }
          else if (prev_page_dirty == false)
            {
              break;      /* clean이 연속 2장 → NEIGHBOR_ABORT_TWO_CONSECTIVE_NONDIRTIES */
            }
        }
      else
        {
          /* 배치 전체의 WAL 대상이 될 "가장 새로운 oldest_unflush_lsa"를 갱신 */
          if (LSA_LT (&log_newest_oldest_unflush_lsa, &bufptr->oldest_unflush_lsa))
            LSA_COPY (&log_newest_oldest_unflush_lsa, &bufptr->oldest_unflush_lsa);
          dirty_pages_cnt++;
        }
      /* clean이 과반이면 배치를 포기한다 */
      if (helper->npages > PGBUF_PAGES_COUNT_THRESHOLD && (2 * dirty_pages_cnt) < helper->npages)
        {  helper->npages = 1;  break;  }   /* NEIGHBOR_ABORT_TOO_MANY_NONDIRTIES */
      prev_page_dirty = pgbuf_bcb_is_dirty (bufptr);
      pgbuf_add_bufptr_to_batch (bufptr, vpid.pageid - first_vpid.pageid);
      PGBUF_BCB_UNLOCK (bufptr);
      i++;
    }
  /* (3) 양 끝이 clean이면 잘라낸다 (배치 경계를 dirty로 맞춘다) */
  if (prev_page_dirty) { 끝단 clean이면 fwd_offset--/back_offset-- 및 npages-- }
  if (helper->npages <= 1)
    {
      /* 이웃을 못 모았다 — 중심 한 장만 flush하고 끝. WAL은 flush_with_wal이 한다 */
      error = pgbuf_flush_neighbor_safe (thread_p, center, &helper->vpids[pos], &was_flushed);
      *flushed_pages = was_flushed ? 1 : 0;
      return error;
    }
  /* (4) ★ 배치 전체의 WAL을 여기서 한 번에 처리한다 */
  logpb_flush_log_for_wal (thread_p, &log_newest_oldest_unflush_lsa);
  /* (5) back_offset부터 fwd_offset까지 순서대로 flush. 실패해도 계속 진행하고
   *     첫 에러만 기억해 반환한다. */
  for (pos = POS (-back_offset); pos <= POS (fwd_offset); pos++)
    {
      error = pgbuf_flush_neighbor_safe (thread_p, helper->pages_bufptr[pos], &helper->vpids[pos], &was_flushed);
      if (error != NO_ERROR) { save_first_error = save_first_error ?: error; continue; }
      if (was_flushed) written_pages++;
    }
  *flushed_pages = written_pages;
  helper->npages = 0;
  return save_first_error;
}

          error = pgbuf_flush_chkpt_seq_list (thread_p, seq_flusher, prev_chkpt_redo_lsa, smallest_lsa);
          if (error != NO_ERROR) { pgbuf_Pool.is_checkpoint = false; return error; }
          flushed_page_cnt_local += seq_flusher->flushed_pages;
          collected_bcbs = 0;
        }

      PGBUF_BCB_LOCK (bufptr);                                            /* [BCB mutex] */

       *     ★ 정렬 키는 oldest_unflush_lsa다 (페이지 현재 LSA가 아니다).
       *     ★ oldest가 NULL인 dirty 페이지(로깅 없이 수정)는 ★포함★된다. */

          || (!LSA_ISNULL (&bufptr->oldest_unflush_lsa)
              && LSA_GT (&bufptr->oldest_unflush_lsa, flush_upto_lsa))
          || pgbuf_is_temporary_volume (bufptr->vpid.volid))              /* temp 볼륨 제외 */
        {
          PGBUF_BCB_UNLOCK (bufptr);  continue;
        }
      /* (4) 직전 checkpoint와의 정합성 검사 — pgbuf_set_lsa가 지키는 것과 같은 불변식 (:4208-4220) */

          && prev_chkpt_redo_lsa != NULL && !LSA_ISNULL (prev_chkpt_redo_lsa)
          && LSA_LT (&bufptr->oldest_unflush_lsa, prev_chkpt_redo_lsa))
        {
          er_stack_push ();
          er_set (ER_ERROR_SEVERITY, ARG_FILE_LINE, ER_LOG_CHECKPOINT_SKIP_INVALID_PAGE, 6, ...);
          er_stack_pop ();
          assert (false);
        }
      f_list[collected_bcbs].bufptr = bufptr;
      VPID_COPY (&f_list[collected_bcbs].vpid, &bufptr->vpid);
      PGBUF_BCB_UNLOCK (bufptr);
      collected_bcbs++;
      if (thread_p != NULL && thread_p->shutdown)                          /* (:4229-4235) */
        {  pgbuf_Pool.is_checkpoint = false;  return ER_FAILED;  }
    }
  /* (5) 마지막 부분 배치                                                   (:4238-4248) */
  if (collected_bcbs > 0)
    {
      seq_flusher->flush_cnt = collected_bcbs;  seq_flusher->flush_idx = 0;
      qsort (f_list, flush_cnt, sizeof (f_list[0]), pgbuf_compare_victim_list);
      error = pgbuf_flush_chkpt_seq_list (thread_p, seq_flusher, prev_chkpt_redo_lsa, smallest_lsa);
      flushed_page_cnt_local += seq_flusher->flushed_pages;
    }
  pgbuf_Pool.is_checkpoint = false;
  if (flushed_page_cnt != NULL) *flushed_page_cnt = flushed_page_cnt_local;
  return error;
}

static int pgbuf_flush_seq_list (thread_p, seq_flusher, limit_time,
                                 prev_chkpt_redo_lsa, chkpt_smallest_lsa, int *time_rem)   /* :4383-4628 */

        {

          if (seq_flusher->control_intervals_cnt < 0) flush_per_interval -= seq_flusher->control_flushed;
        }
    }

    {
      avail_time_msec = -1;                            /* 시간 제한 없음 */

    }

                            (PGBUF_CHKPT_MIN_FLUSH_RATE * seq_flusher->interval_msec) / 1000.0f);   /* MIN=50 */

       *     ⇒ run 중간의 페이지는 이미 깨끗해도 다시 쓴다(하나의 긴 순차 쓰기 유지). */

      if (flush_idx + 1 >= flush_cnt
          || f_list[flush_idx].vpid.pageid + 1 != f_list[flush_idx + 1].vpid.pageid)
        {
          flush_if_already_flushed = false;
        }
      PGBUF_BCB_LOCK (bufptr);  locked_bcb = true;                        /* [BCB mutex] */
      /* (3) 탈락 조건                                                     (:4485-4492) */

          || !pgbuf_bcb_is_dirty (bufptr)
          || (flush_if_already_flushed == false
              && !LSA_ISNULL (&bufptr->oldest_unflush_lsa)
              && LSA_GT (&bufptr->oldest_unflush_lsa, &seq_flusher->flush_upto_lsa)))
        {
          PGBUF_BCB_UNLOCK (bufptr);  dropped_pages++;  continue;
        }
      /* (4) 동기 flush. force_lock이므로 성공 시 BCB는 잠긴 채 돌아온다    (:4495) */

      if (pgbuf_bcb_safe_flush_force_lock (thread_p, bufptr, true /*synchronous*/) == NO_ERROR)

          if (!LSA_ISNULL (&bufptr->oldest_unflush_lsa)
              && LSA_LE (&bufptr->oldest_unflush_lsa, &seq_flusher->flush_upto_lsa))

               *  전부터 flush 중이었고, 그 사이 또 수정됐고, 새 oldest_unflush_lsa가
               *  flush_upto_lsa보다 작다고 가정해 보자. 여러 행성이 정렬되어야 할 것 같지만,
               *  보수적으로 한 번 더 flush하자." */
              if (pgbuf_bcb_safe_flush_internal (thread_p, bufptr, true, &locked_bcb) == NO_ERROR)
                {
                  assert (LSA_ISNULL (&bufptr->oldest_unflush_lsa)
                          || LSA_GT (&bufptr->oldest_unflush_lsa, &seq_flusher->flush_upto_lsa));
                  done_flush = true;
                }
              else  assert (false);
            }
          else
            {
              done_flush = true;
            }
        }
      else
        {
          assert (false);  locked_bcb = false;      /* force_lock은 에러 시 unlock한다 */
        }
      if (done_flush)
        {
          seq_flusher->flushed_pages++;
        }
      else
        {
          assert (false);
          if (!locked_bcb) { PGBUF_BCB_LOCK (bufptr); locked_bcb = true; }
          /* (5) ★ flush하지 못한 페이지에서만 smallest를 갱신한다          (:4544-4549)
           *     이 값이 다음 checkpoint의 redo LSA가 된다. */
          if (!LSA_ISNULL (&bufptr->oldest_unflush_lsa)
              && (LSA_ISNULL (chkpt_smallest_lsa)
                  || LSA_LT (&bufptr->oldest_unflush_lsa, chkpt_smallest_lsa)))
            {
              LSA_COPY (chkpt_smallest_lsa, &bufptr->oldest_unflush_lsa);
            }
        }
      if (locked_bcb) { PGBUF_BCB_UNLOCK (bufptr); locked_bcb = false; }
      /* (6) 시간 초과 판정                                                (:4559-4568) */
      if (limit_time != NULL && !ignore_time_limit)
        {
          gettimeofday (&cur_time, NULL);
          if (cur_time >= *limit_time) { *time_rem = -1; break; }
        }
      /* (7) 비-burst 모드에서만 페이지 사이에 잔다.
       *     계산된 sleep이 1000/PGBUF_CHKPT_MAX_FLUSH_RATE(=1200) ms를 넘을 때만 실제로 잔다 (:4570-4587) */
      if (!seq_flusher->burst_mode && seq_flusher->flush_rate > 0
          && seq_flusher->flushed_pages < flush_per_interval && !ignore_time_limit)
        {
          sleep_msecs = (limit_time != NULL)
                        ? timeval_diff_in_msec (limit_time, &cur_time) / (flush_per_interval - flushed_pages)
                        : 1000.0f / seq_flusher->flush_rate;
          if (sleep_msecs > (1000.0f / PGBUF_CHKPT_MAX_FLUSH_RATE)) thread_sleep (sleep_msecs);
        }
      if (thread_p && thread_p->shutdown) return ER_FAILED;
    }
  /* (8) 1초 창 보상 부기                                                   (:4596-4618) */
  gettimeofday (&cur_time, NULL);
  if (limit_time != NULL)
    {
      *time_rem = timeval_diff_in_msec (limit_time, &cur_time);
      seq_flusher->control_intervals_cnt++;
      if (seq_flusher->control_intervals_cnt >= control_total_cnt_intervals || ignore_time_limit)
        {
          seq_flusher->control_intervals_cnt = 0;
        }
      if (seq_flusher->control_intervals_cnt == 0)  seq_flusher->control_flushed = 0;
      else                                          seq_flusher->control_flushed += seq_flusher->flushed_pages;
    }
  return error;
}

  VPID_COPY (&vpid_to_flush, (VPID *) rcv->data);
  page = pgbuf_fix (thread_p, &vpid_to_flush, OLD_PAGE_MAYBE_DEALLOCATED,
                    PGBUF_LATCH_WRITE, PGBUF_UNCONDITIONAL_LATCH);
  if (page == NULL)
    {
      er_clear ();  return NO_ERROR;        /* 페이지가 이미 없어졌다 — 정상 종료 */
    }
  /* 논리적 시스템 연산 종료가 불평하지 않도록 더미 로그를 남긴다 */
  log_append_empty_record (thread_p, LOG_DUMMY_GENERIC, &addr);
  pgbuf_set_dirty (thread_p, page, DONT_FREE);
  pgbuf_flush (thread_p, page, DONT_FREE);
  pgbuf_unfix (thread_p, page);
  return NO_ERROR;
}

8.11.2 수용 기준

수용 테스트 — quiz 03 / 04 / 10 기대 패턴 quiz 03 (dirty lazy write). 2,000행 UPDATE + COMMIT 직후: Num_data_page_dirties는 크게 증가(호출 횟수 기준 — 2,000행에 약 9,600회), Num_data_page_iowrites는 대략 0(백그라운드 flush가 끼어들지 않는 한), 게이지 Num_data_page_dirty는 ~50장 수준. 재구현이 dirty를 즉시 쓰거나 카운터를 전이 기준으로 바꾸면 여기서 즉시 어긋난다.

quiz 04 (WAL before data). 1,000행 INSERT + COMMIT 직후: Num_log_append_records·Num_log_page_iowrites 증가, Num_data_page_iowrites는 0, 그리고 Num_log_wals는 0일 수 있다 — 이 카운터는 "커밋의 로그 flush"가 아니라 "페이지 flush가 로그 flush를 끌고 나온 횟수"이기 때문이다. 8.3.4의 WAL 게이트를 잘못 구현하면(예: 항상 logpb_flush_log_for_wal 호출) 이 값이 0이 아니게 되어 바로 드러난다.

  • iowrites가 dirty 페이지 수의 약 2배인 이유는 D6(a): DWB가 켜져 있으면 페이지당 (1) DWB 파일 쓰기 + (2) 원위치 쓰기 = 2회가 각각 PSTAT_PB_NUM_IOWRITES로 집계된다. pgbuf 쪽 :10831은 DWB 사용 시 전혀 오르지 않고, DWB 내부가 대신 올린다. 반면 SHOW의 Num_pages_written은 비-DWB 분기에서만 올라 DWB on에서 과소 집계된다 — 이 두 방향의 어긋남을 MUST 그대로 재현한다.
구현 자체 점검 목록 (M5·M6 게이트)
  1. WAL 순서 위반 0: 임의 시점 크래시 후 재기동에서 logpb_need_wal이 참인 페이지가 디스크에 존재하지 않아야 한다.
  2. 0 <= dirties_cnt <= num_buffers가 부하 중 항상 성립(assert 유지).
  3. victim flush 패스마다 에러 로그에 ER_LOG_FLUSH_VICTIM_STARTED/ _FINISHED 쌍이 정확히 하나씩.
  4. FLUSHING_TO_DISK가 켜진 채 방치된 BCB가 shutdown 시점에 0개 (D1을 수정했다면 자연히 성립, 충실 재현했다면 TDE 미사용 환경에서 성립).
  5. checkpoint 후 smallest_lsa가 남은 dirty 페이지들의 oldest_unflush_lsa 최솟값과 일치.
  6. page_flush_interval_in_msecs = 0에서도 서버가 정상 동작(8.5.2의 keep-running 술어가 계속 참이 되는 것이 정상).
