**Inference / relation:** the existing CI pruning policy removes that unassigned shared fixture. This is a direct test-packaging incompatibility, high confidence; engine runtime assertions were not reached.

**Unknown:** an independent filesystem listing before launch was not captured. Other dependencies could fail after this first blocker is fixed.
