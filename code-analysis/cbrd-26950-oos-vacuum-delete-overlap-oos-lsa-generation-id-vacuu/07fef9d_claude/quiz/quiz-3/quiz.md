## 질문

- **Q1.** 채널 A(판독 불가가 된 커밋 행)와 채널 B(두 pass 모두에서 삭제된 OID)는 왜 강도가
  다른가? 채널 B 에 섞일 수 있는 "결함이 아닌" 재삭제의 예를 하나 들어라.
- **Q2.** 대조군(gen-1, id 1..20000)이 **구조적으로** 무손상일 수밖에 없는 이유는?
  ("운이 좋아서"가 아닌 답을 요구한다.)
- **Q3.** 두 번째 `oos_delete` 직전, 엔진이 아는 것과 알 수 없는 것을 각각 한 문장으로 쓰라.
- **Q4.** 피해 행의 payload 가 멀티청크 체인이었다면 피해는 어떻게 달라지는가? 근거 코드 지점은?
- **Q5.** 이 실험에서 관측된 오류(`slot N ... is not allocated`)보다 운영에서 더 나쁜 결과는
  무엇이고, 실험은 그것을 어떻게 감지하도록 설계돼 있나?
- **Q6.** 같은 스크립트의 두 실행이 다른 관계를 보였다: rep 2 는 채널 A:B = 233:233(1:1), rep 1 은
  528:12,432. 두 실행의 *어떤 차이* 가 이 간극을 만들었다고 보는가? 그리고 보고서가 이 간극에 대해
  취한 태도(단정/추정/unknown)는 무엇이며 왜 그것이 옳은가?
