호환성 한계 (재확인)

이 blueprint 는 개념·행동 재구현용이다. ABI·온디스크 바이트·타이밍·성능 동등성은 범위 밖이며, 설계안(generation/OOS LSA/update log)은 미구현이므로 "현행 CUBRID 와의 호환"이 아니라 "결함 없는 재구현의 계약"을 정의한다. 6b 의 정확성이 4개 서브시스템 불변식에 조건부라는 사실이 보여주듯, 이 계약의 판정들은 현행 구현의 명시된 불변식에 조건부다 — 불변식이 바뀌면 ch16 의 표를 다시 평가해야 한다.

준비 선언 (Readiness Declaration)

READY WITHIN DECLARED SCOPE — 선언된 범위(ch01) 안에서, 독립 구현자가 소스를 다시 열지 않고 다음에 답할 수 있다: Interface 와 호출자 의무(ch03, ch16 §9) / 상태 소유·수명(ch04) / 연산 전후 상태(ch06 표) / 재시도·대기·실패 조건(ch05, ch10) / 보호 장치와 획득 순서(ch07) / 크래시 생존과 재구성(ch08) / 영속 레이아웃(ch04, ch11 — 단 바이트 호환은 비약속) / 기동·중단·복구 순서(ch05, ch08) / 재구축 순서(ch16 §9) / 적합성 테스트(ch16 §9 — experiment-1/2 오라클). Unknown U1–U7 은 전부 이 선언의 경계 밖 이거나(U1: 회의 의도 확인, U3–U5: 이웃 검증) 결론에 영향 없는 측정 심화(U2, U6, U7)로 분류되며, 숨긴 미지수는 없다.
