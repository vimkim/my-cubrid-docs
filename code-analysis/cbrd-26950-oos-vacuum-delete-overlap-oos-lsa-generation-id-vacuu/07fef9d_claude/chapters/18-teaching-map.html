ch18 — Teaching Map: 챕터·퀴즈·grill 의 연결

이 장의 용도

학습자가 지금 어디에 있고 무엇으로 확인할지 찾는 지도다. 정적 퀴즈는 quiz/quiz-N/ 디렉터리(한국어 문제·답·실행 스크립트)에 있고, live grill 은 아래 8개 마스터리 영역을 하나씩 질문한다.
