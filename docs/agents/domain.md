# Domain Docs

Before exploring, read the root `CONTEXT.md` when it exists and ADRs under `docs/adr/` that affect the work. If either is absent, proceed silently; domain-modeling workflows create them lazily.

Use glossary terms exactly and avoid synonyms marked under `_Avoid_`. Surface conflicts with existing ADRs explicitly.
