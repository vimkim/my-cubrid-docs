dirty는 변경된 버퍼 상태, checkpoint는 변경 내용을 디스크에 반영해 복구 시작점을 전진시키는 절차입니다.
BCB / holder
BCB는 페이지 슬롯의 관리 정보, holder는 스레드가 어떤 페이지를 몇 번 잡았는지 기록한 정보입니다.
TDE / DWB / WAL
TDE는 데이터 암호화, DWB는 불완전한 페이지 쓰기에 대비한 이중 쓰기, WAL은 데이터보다 로그를 먼저 기록하는 규칙입니다.
SX
다른 읽기는 허용하면서 쓰기를 막는 중간 잠금의 제안 모드입니다. 적용 효과와 잠금 순서를 조사해야 합니다.
debug / release / SA
debug는 검증용, release는 최적화된 제품용 빌드입니다. SA는 서버와 클라이언트를 한 프로세스에서 쓰는 모드입니다. 추가 스위치 CUBRID_DEBUG는 일반 debug 빌드와 다릅니다.
Lean 모델
명시한 규칙 아래 명제나 반례를 검사하는 모델입니다. 실제 엔진 실행이나 성능 측정 결과를 대신하지 않습니다.
