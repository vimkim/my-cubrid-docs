Three identities, two routing passes

Source class / attr_info
The write cache's class metadata and assignments. Moving UPDATE still reads the old record through its source identity.
Early destination / write_destination
The child class selected from the effective key. Supplies the owner for new OOS values; it is not permission to bypass final force.
Final destination
The child selected from the real serialized record. Must agree with the early destination; existing final representation/locking/index/movement behavior remains.

Remember

effective key → early child → owner-aware first pass → final record route → agreement → write/move

A small key codec is not a full inline-row probe. One full-row transformation is not zero copyarea, zero payload serialization, or zero retries. New OOS allocation does not by itself authorize old-chain deletion.
