Quick reference

Partition selection

Pruning

Ruling out partitions that cannot apply. For an insert, select the destination; for a read, exclude partitions that cannot contribute matching rows. Neither meaning implies deleting stored rows.

Range boundary

With p0: id < 10 and p1: id ≥ 10, id = 10 belongs to p1.

Heap file

Database storage holding rows. Each partition in this example has its own heap. This is distinct from the process memory heap.
