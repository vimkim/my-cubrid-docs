# OOS 머지 준비

OOS 완료 보고와 develop 통합 준비를 논의하는 용어집이다. OOS 저장 구조와 동작의 기준은 `/home/vimkim/gh/cubrid-oos-context/OOS-CONTEXT.md`이다.

## Language

**머지 준비 완료**:
합의한 수정과 검증을 마친 기술적 준비 상태다. 외부 승인 대기와 실제 머지 완료는 별도로 표시한다.
_Avoid_: 머지 완료, OOS 전체 개발 종료

**외부 승인 대기**:
기술적 준비와 별개로 실제 머지에 필요한 maintainer/admin 등의 승인이 아직 확보되지 않은 상태다.
_Avoid_: 머지 가능, 검증 실패

**검증 차단**:
필요한 테스트 판정을 뒷받침할 증거를 확보할 수 없어 기술적 준비 완료를 선언할 수 없는 상태다.
_Avoid_: 통과, OOS 결함 확정

**실제 머지 완료**:
OOS 통합 변경이 develop에 반영되고 원격 상태로 확인된 상태다.
_Avoid_: 보고서 게시 완료, 머지 준비 완료

**원인 불명 비CDC 실패**:
CDC 연기 범위 밖에서 관측됐으나 원인 분류에 필요한 증거가 충분하지 않은 테스트 실패다.
_Avoid_: 확인된 OOS 결함, develop 기존 실패

**비교 미완료 항목**:
feature와 develop의 비교 결과를 판정할 근거가 아직 완성되지 않은 항목이다.
_Avoid_: 회귀 없음, 기존 실패
